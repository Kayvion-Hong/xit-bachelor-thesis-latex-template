# README 配图练习项目

[下载练习项目 ZIP](quickstart-demo.zip) · [查看已编译的 PDF](quickstart-demo.pdf) · [返回主 README](../../README.md)

这份材料对应主 README 中的封面、摘要、标题、图片、表格、公式、文献和附录配图。它使用空白模板原有的 `xitthesis.cls` 和 `figures/logo.png`，仅添加练习内容，没有修改模板样式文件。

## 怎么使用

在 Overleaf 另建一个项目，上传 `quickstart-demo.zip`，将编译器设为 XeLaTeX、主文件设为 `main.tex`，再编译。不要上传 `docs/` 整个文件夹，它还包含说明和预览，不是需要编辑的论文项目。

也可以解压练习 ZIP，在包含 `main.tex` 的文件夹中依次运行：

```bash
xelatex main.tex
biber main
xelatex main.tex
xelatex main.tex
```

先在 `main.tex` 中改姓名，确认封面更新；接着在 `chap/chapter1.tex` 中修改某个节标题，检查正文和目录；最后改动图题或表题，再检查其正文引用。文献引用使用了明确标记的虚构条目，请不要用于正式论文。

插图练习使用项目自带的 `figures/logo.png`，不需要另外下载图片。进入正式写作时，应当回到空白论文模板，填写自己的研究内容，而不是把练习项目直接作为论文提交。

为了使各项练习可以分别截图，`chap/chapter1.tex` 在几个示例之间使用了 `\clearpage`。这是配图练习的分页安排，不表示普通论文每一节都需要强制分页，源文件中也有相应注释。
